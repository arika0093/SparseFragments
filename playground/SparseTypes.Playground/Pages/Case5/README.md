# Case 5: EF Core mapping

This folder contains the EF Core mapping, page, and sample code. `OrderLineRow` edits line fields through `SparseField` and routes collection changes through the typed collection editor. The mapper owns DTO projection, including the flattened Notes read and line ordering. `SaveSnackbar` shows progress during a delayed save. The submit action captures an immutable ChangeSet through the generated EditSession; the baseline advances when the save is acknowledged, and standard conflicts offer a per-path choice between the captured submitted value and the current persisted value. Later draft edits remain pending after reconciliation. An optional 10-second simulation writes through a separate DbContext, reports the persisted revision and changed field, and never mutates the draft; it stops when disabled, reseeded, or disposed.
