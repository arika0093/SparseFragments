# Case 5: EF Core mapping

This folder contains the EF Core mapping, page, and sample code. `OrderLineRow` edits line fields through `SparseField` and routes collection changes through the typed collection editor. The mapper owns DTO projection, including the flattened Notes read and line ordering. `SaveSnackbar` shows progress during a delayed save. The submit action captures an immutable ChangeSet through the generated EditSession; after a successful save, the session reconciles against the persisted entity and the UI adopts authoritative values for untouched fields. Standard conflicts offer a per-path choice between the captured submitted value and the current persisted value. Later draft edits remain pending after reconciliation. An optional 10-second simulation writes through a separate DbContext and shows the latest Customer and Notes values below their fields without mutating the draft; it stops when disabled, reseeded, or disposed.
